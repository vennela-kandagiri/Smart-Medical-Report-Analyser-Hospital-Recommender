# 🏥 Smart Medical Report Analyzer & Hospital Recommendation System

## 📌 Overview

The Smart Medical Report Analyzer & Hospital Recommendation System is an AI-powered healthcare automation solution that simplifies the interpretation of medical reports. The system extracts key medical information from uploaded reports, generates an easy-to-understand summary using Google Gemini AI, and recommends nearby hospitals based on the patient's location through an automated workflow built with n8n.

This project aims to reduce the complexity of medical reports and assist patients in making informed healthcare decisions.

---

## 🚀 Features

- Upload and analyze medical reports
- AI-powered medical report summarization using Google Gemini
- Extracts important health information from reports
- Generates patient-friendly explanations
- Recommends nearby hospitals based on user location
- Automated workflow using n8n
- Sends summarized reports via email
- Reduces manual effort through workflow automation

---

## 🛠️ Tech Stack

- AI Automation
